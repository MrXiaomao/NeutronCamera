1. 概述

HDA 客户端 DLL（HL实验数据访问接口）是一个用于连接到 HDA 服务器并读写HDF5实验数据的动态链接库。 该库提供了标准化的 C API 接口，支持多种编程语言调用，包括 C++、MATLAB、Python、LabVIEW 等。 HDA 客户端采用 gRPC 和 Protocol Buffers 实现高性能的数据采集通信。 通过零拷贝传输和批量写入机制，能够高效处理大规模实验数据，满足 HL-3 装置对数据采集的实时性和可靠性要求。

本文档面向HL-3用户，详细说明了 DLL 的使用方法、数据结构定义、API 函数接口以及各语言的调用示例。 通过本指南，用户可以快速集成 HDA 客户端到自己的应用程序中，实现实验数据的采集、存储和查询功能。

主要特性

  • 高性能通信：基于 gRPC 的流式接口，支持零拷贝传输
  • 批量写入：支持大批量数据传输，提高数据采集效率
  • 多线程安全：支持并发读写操作
  • 标准数据格式：使用 HDF5 格式存储实验数据

2. 头文件说明

使用 DLL 时需要包含头文件 hda_client.h，该文件定义了所有数据结构、枚举类型和函数接口。

2.1 核心句柄类型

hda_client_t 客户端句柄，不透明指针类型，用于标识客户端连接 typedef void*
hda_writer_t 写入器句柄，不透明指针类型，用于标识写入会话 typedef void*

2.2 数据类型枚举

HDA_DT_FLOAT32 = 0 32 位浮点数
HDA_DT_STRING = 1 UTF-8 字符串（变长）
HDA_DT_INTEGER32 = 2 32 位有符号整数
HDA_DT_RAW_DIO = 3 8 位数字 IO
HDA_DT_RAW_U16 = 4 16 位无符号整数
HDA_DT_RAW_U32 = 5 32 位无符号整数
HDA_DT_INTEGER16 = 6 16 位有符号整数
HDA_DT_FLOAT64 = 7 64 位浮点数

2.3 时间模式枚举

HDA_TIME_MODE_FULL_ARRAY = 0 完整时间数组模式
HDA_TIME_MODE_START_FREQ = 1 起始时间+频率模式

2.4 读取模式枚举

HDA_READ_MODE_CONTINUOUS = 0 连续读取模式，返回指定范围内的所有数据点
HDA_READ_MODE_UNIFORM_SAMPLING = 1 均匀采样模式，指定返回数量，服务端按间隔均匀抽取数据点

2.5 数据维度枚举

HDA_DIM_0D = 1 标量数据
HDA_DIM_1D = 2 一维数组
HDA_DIM_ND = 3 多维数组 (N>=2)

2.5 状态码枚举

HDA_OK = 0 操作成功
HDA_E_INVALID_ARG = 1 无效参数
HDA_E_NOT_INITIALIZED = 2 未初始化
HDA_E_NETWORK = 4 网络错误
HDA_E_TIMEOUT = 5 超时
HDA_E_BACKPRESSURE = 6 背压（消息过大）
HDA_E_NOT_FOUND = 7 未找到数据
HDA_E_IO = 8 IO 错误
HDA_E_UNAUTHENTICATED = 9 未认证或 Token 无效
HDA_E_AUTH_FAILED = 10 认证失败
HDA_E_INTERNAL = 100 内部错误

4. C++ 调用方法

4.1 概述

本章节详细介绍如何在 C++ 程序中使用 HDA 客户端 DLL。HDA 客户端提供了完整的 C API 接口，支持数据的写入和读取操作。 主要包括以下功能模块：

  • 客户端初始化：配置服务器地址并建立连接
  • 数据写入：支持 0D（标量）和 1D（时序）数据的写入
  • 数据读取：支持按通道读取历史数据
  • 资源管理：正确释放客户端和写入器资源

4.2 基本操作流程

使用 HDA 客户端的基本流程包括：初始化客户端、打开写入器、执行数据操作、关闭句柄、清理资源。 本节介绍各个基本操作的调用方法。

4.2.1 连接服务器

首先需要包含头文件 hda_client.h，然后配置客户端参数并连接到服务器。 

// 包含头文件
#include "hda_client.h"

// 初始化客户端配置
hda_client_t client;
hda_client_config_t cfg;
cfg.server_address = "172.30.20.11:9090";

// 连接到服务器
hda_status_t status = hda_client_connect(&cfg, &client);
if (status != OK) {
    printf("Failed to connect: %d\n", status);
    return -1;
}

4.2.2 打开写入器

写入器用于向 HDA 服务器写入实验数据。打开写入器需要指定装置、炮号、子系统等关键信息。 

// 设置写入键
hda_write_key_t key;
key.device = "HL-3";
key.shot = 12345;
key.subsystem = "test_subsystem";


// 打开写入器
hda_writer_t writer;
status = hda_open_writer(client, &key, &writer);
if (status != OK) {
    printf("Failed to open writer: %d\n", status);
    return -1;
}

4.2.3 断开连接

使用完客户端后，需要调用 hda_client_disconnect 函数断开连接并释放所有相关资源。 

// 断开连接，释放所有资源
hda_client_disconnect(client);

4.3 数据写入操作

HDA 客户端支持两种数据类型的写入：1D 时序数据和 0D 标量数据。本节详细介绍这两种数据的写入方法。

4.3.1 写入 1D 数据

1D 数据通常用于存储随时间变化的测量信号，如电压、电流、温度等。写入 1D 数据需要提供时间数组和对应的值数组。 

// 准备时间数组
std::vector<double> time = {0.0, 1.0, 2.0, 3.0, 4.0};

// 准备值数组
std::vector<float> values = {10.0f, 20.0f, 30.0f, 40.0f, 50.0f};

// 设置通道属性
hda_channel_attr_t attrs = {0};
attrs.DEVICE = "HL-3";
attrs.CONTACT_INFO = "";
attrs.DAQ_DTYPE = "PROCD";
attrs.DAQ_RAW_BITS = 16;
attrs.DAQ_VALIDITY = 1;
attrs.DATA_TYPE = HDA_DT_FLOAT32;
attrs.DESCRIPTION = "Voltage measurement channel";
attrs.EBAR_EXIST = 0;
attrs.ENTRY_TIME = "2026-01-24 10:00:00";
attrs.PHI_DIM = -1;
attrs.R_DIM = -1;
attrs.T_COORD_FREQ = 1000.0f;
attrs.T_COORD_START = 0.0f;
attrs.T_DIM = 5;
attrs.T_TYPE = "US";
attrs.T_UNIT = "s";
attrs.VERSION = 1;
attrs.V_UNIT = "V";
attrs.Z_DIM = -1;

// 准备写入请求
hda_write_1d_req_t req;
req.channel = "test_channel_1d";
req.dtype = HDA_DT_FLOAT32;
req.count = 5;
req.pTime = time.data();
req.pValue = values.data();
req.attrs = &attrs;  // 设置通道属性指针

// 写入数据
status = hda_write_1d(writer, &req);
if (status != OK) {
    printf("Failed to write 1D data: %d\n", status);
    return -1;
}

4.3.2 写入 0D 数据

0D 数据用于存储标量参数，如控制参数、状态标志、配置值等。写入 0D 数据只需要提供单个值。 

// 准备参数值
int32_t value = 42;

// 设置通道属性
hda_channel_attr_t attrs = {0};
attrs.DEVICE = "HL-3";
attrs.CONTACT_INFO = "";
attrs.DAQ_DTYPE = "PROCD";
attrs.DAQ_RAW_BITS = 16;
attrs.DAQ_VALIDITY = 1;
attrs.DATA_TYPE = HDA_DT_INTEGER32;
attrs.DESCRIPTION = "Control parameter";
attrs.EBAR_EXIST = 0;
attrs.ENTRY_TIME = "2026-01-24 10:00:00";
attrs.PHI_DIM = -1;
attrs.R_DIM = -1;
attrs.T_COORD_FREQ = 0.0f;
attrs.T_COORD_START = 0.0f;
attrs.T_DIM = -1;
attrs.T_TYPE = "";
attrs.T_UNIT = "";
attrs.VERSION = 1;
attrs.V_UNIT = "";
attrs.Z_DIM = -1;

// 准备写入请求
hda_write_0d_req_t req;
req.channel = "test_param_0d";
req.dtype = HDA_DT_INTEGER32;
req.count = 1;
req.data = &value;
req.attrs = &attrs;  // 设置通道属性指针

// 写入数据
status = hda_write_0d(writer, &req);
if (status != OK) {
    printf("Failed to write 0D data: %d\n", status);
    return -1;
}

4.3.3 关闭写入器

完成所有数据写入后，需要关闭写入器。关闭操作会等待服务器确认所有数据已成功写入。 建议设置合理的超时时间（单位：毫秒）。 

// 关闭写入器，等待服务器确认
status = hda_close_writer(writer, 5000);
if (status != OK) {
    printf("Failed to close writer: %d\n", status);
    return -1;
}

4.4 数据读取操作

数据读取操作用于从 HDA 服务器获取历史实验数据。支持索引读取、时间范围查询和最后N点查询三种模式。 读取操作会返回时间数组和对应的值数组。 

// 设置读取请求
hda_read_req_t read_req;
read_req.shot = 12345;
read_req.channel = "test_channel_1d";
read_req.mode = HDA_READ_MODE_CONTINUOUS;
read_req.start_index = 0;  // 起始索引
read_req.count = 100;      // 读取数量
read_req.return_timebase = 1;  // 返回时间基线

// 准备缓冲区
const int kMaxBufferSize = 1000000;
std::vector<double> read_time(kMaxBufferSize);
std::vector<float> read_values(kMaxBufferSize);

hda_read_1d_resp_t read_resp;
read_resp.out_time = read_time.data();
read_resp.out_time_bytes = read_time.size() * sizeof(double);
read_resp.out_value = read_values.data();
read_resp.out_value_bytes = read_values.size() * sizeof(float);

// 读取数据
status = hda_read_1d(client, &read_req, &read_resp);
if (status != OK) {
    printf("Failed to read 1D data: %d\n", status);
} else {
    printf("Read %d samples\n", read_resp.sample_count);
    for (int i = 0; i < read_resp.sample_count; i++) {
        printf("  Time: %.2f, Value: %.2f\n", read_time[i], read_values[i]);
    }
}

4.5 完整示例程序

以下是一个完整的 C++ 示例程序，演示了 HDA 客户端的完整使用流程，包括连接、数据写入、数据读取和断开连接。 该示例可以作为开发 HDA 客户端应用程序的参考模板。 

// demo_hda_client.cpp
#include "hda_client.h"
#include <iostream>
#include <vector>

using namespace std;

int main() {
    // 连接到服务器
    hda_client_t client;
    hda_client_config_t cfg;
    cfg.server_address = "172.30.20.11:9090";

    hda_status_t status = hda_client_connect(&cfg, &client);
    if (status != OK) {
        cout << "Failed to connect: " << status << endl;
        return -1;
    }
    cout << "Connected successfully" << endl;

    // 写入数据
    {
        // 设置写入键
        hda_write_key_t key;
        key.device = "HL-3";
        key.shot = 12345;
        key.subsystem = "test_subsystem";
     

        // 打开写入器
        hda_writer_t writer;
        status = hda_open_writer(client, &key, &writer);
        if (status != OK) {
            cout << "Failed to open writer: " << status << endl;
            hda_client_disconnect(client);
            return -1;
        }

        // 准备1D数据
        vector<double> time = {0.0, 1.0, 2.0, 3.0, 4.0};
        vector<float> values = {10.0f, 20.0f, 30.0f, 40.0f, 50.0f};

        // 设置通道属性
        hda_channel_attr_t attrs = {0};
        attrs.DEVICE = "HL-3";
        attrs.CONTACT_INFO = "";
        attrs.DAQ_DTYPE = "PROCD";
        attrs.DAQ_RAW_BITS = 16;
        attrs.DAQ_VALIDITY = 1;
        attrs.DATA_TYPE = HDA_DT_FLOAT32;
        attrs.DESCRIPTION = "Voltage measurement channel";
        attrs.EBAR_EXIST = 0;
        attrs.ENTRY_TIME = "2026-01-31 10:00:00";
        attrs.PHI_DIM = -1;
        attrs.R_DIM = -1;
        attrs.T_COORD_FREQ = 1000.0f;
        attrs.T_COORD_START = 0.0f;
        attrs.T_DIM = 5;
        attrs.T_TYPE = "US";
        attrs.T_UNIT = "s";
        attrs.VERSION = 1;
        attrs.V_UNIT = "V";
        attrs.Z_DIM = -1;

        // 准备写入请求
        hda_write_1d_req_t req;
        req.channel = "test_channel_1d";
        req.dtype = HDA_DT_FLOAT32;
        req.count = 5;
        req.pTime = time.data();
        req.pValue = values.data();
        req.attrs = &attrs;

        // 写入数据
        status = hda_write_1d(writer, &req);
        if (status != OK) {
            cout << "Failed to write 1D data: " << status << endl;
            hda_close_writer(writer, 5000);
            hda_client_disconnect(client);
            return -1;
        }
        cout << "1D data written successfully" << endl;

        // 关闭写入器
        status = hda_close_writer(writer, 5000);
        if (status != OK) {
            cout << "Failed to close writer: " << status << endl;
            hda_client_disconnect(client);
            return -1;
        }
        cout << "Writer closed successfully" << endl;
    }

    // 读取数据
    {
        // 设置读取请求
        hda_read_req_t read_req;
        read_req.shot = 12345;
        read_req.channel = "test_channel_1d";
        read_req.mode = HDA_READ_MODE_CONTINUOUS;
        read_req.start_index = 0;
        read_req.count = 100;
        read_req.return_timebase = 1;

        // 准备缓冲区
        const int kMaxBufferSize = 1000000;
        vector<double> read_time(kMaxBufferSize);
        vector<float> read_values(kMaxBufferSize);

        hda_read_1d_resp_t read_resp;
        read_resp.out_time = read_time.data();
        read_resp.out_time_bytes = read_time.size() * sizeof(double);
        read_resp.out_value = read_values.data();
        read_resp.out_value_bytes = read_values.size() * sizeof(float);

        // 读取数据
        status = hda_read_1d(client, &read_req, &read_resp);
        if (status != OK) {
            cout << "Failed to read 1D data: " << status << endl;
        } else {
            cout << "Read " << read_resp.sample_count << " samples" << endl;
            for (int i = 0; i < read_resp.sample_count; i++) {
                cout << "  Time: " << read_time[i] << ", Value: " << read_values[i] << endl;
            }
        }
    }

    // 断开连接
    hda_client_disconnect(client);
    cout << "Disconnected successfully" << endl;

    return 0;
}

4.6.5 故障排除

在编译和部署过程中，可能会遇到一些常见问题。以下是常见问题及其解决方案。

问题：找不到头文件 确保 hda_client.h 在项目目录中，或在编译选项中指定正确的包含路径（/I）
问题：链接错误 - 找不到符号 检查是否正确链接了 hda_client.lib，确保架构匹配（x64 vs x86）
问题：找不到 DLL 文件 确保所有依赖的 DLL 文件都在应用程序目录中

问题：应用程序崩溃 检查运行时库版本是否匹配，使用调试器查看崩溃堆栈

重要提示

1. 架构一致性：确保应用程序和所有依赖库的架构一致（x64 vs x86）。 混合使用不同架构的库会导致运行时错误。

2. 运行时库版本：确保目标机器安装了正确版本的 Visual C++ Redistributable。 不同版本的运行时库可能不兼容。

3. DLL 文件完整性：确保所有必需的 DLL 文件都已复制到应用程序目录， 缺少任何一个都会导致程序无法运行。

4. 网络配置：确保目标机器可以访问 HDA 服务器，检查防火墙规则和网络连接。

9. 常见问题

Q: 如何解决 "找不到 DLL" 错误？

确保 DLL 文件在应用程序目录或系统 PATH 中，或使用绝对路径加载。 Windows 系统需要将 DLL 放在应用程序同级目录或系统目录（如 C:\Windows\System32）。

Q: 支持哪些操作系统？

支持 Windows 7 SP1 及以上版本（64 位）。 需要安装 Microsoft Visual C++ Redistributable 2019 或更高版本。

Q: 如何处理大数据量？

使用流式写入，分批写入数据，避免单次传输过大。 建议每批不超过 10000 个样本。

Q: 连接超时怎么办？

检查网络连接，确认服务器地址和端口正确，检查防火墙设置。 确保服务器端服务正常运行。

Q: 如何设置通道属性？

通道属性通过 hda_channel_attr_t 结构设置。 如果不需要设置属性，可以将 attrs 字段设置为 NULL。 建议至少设置 DESCRIPTION、V_UNIT、T_UNIT 等基本属性。
